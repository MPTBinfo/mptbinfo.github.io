# MPTBinfo Central Link Tree

Static, responsive landing page for the MPTBinfo digital tools and project repositories. The page includes searchable application cards and links to relevant project repositories and official tourism resources.

## Preview

Open `index.html` locally, or visit the published GitHub Pages site: https://mptbinfo.github.io/.

## Maintenance

- Keep project names and links aligned with the current repositories and deployment URLs.
- Do not publish private repository contents, credentials, participant data, or internal documents through this public page.
- The link tree is a navigation aid; official MPTB policy and public information should be verified at the official source.
